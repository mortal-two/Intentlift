# Capability 层:能力契约

成熟工具卖的是**清晰的能力边界**,不是"号称万能"。能力边界是**设计出来的**,在启动阶段就写死。本层定义 IntentIR 覆盖什么、不覆盖什么、对覆盖内的给什么级别保证。

## 何时读

- 决定"要不要支持某类 kernel 模式"之前。
- 对外声明覆盖范围、写 paper claim 之前。

## 文件

| 文件 | 内容 |
|---|---|
| [capability-matrix.md](capability-matrix.md) | 能力矩阵:每种 kernel 模式的可表示 / 可提取 / 可验证(保证级)/ v1 是否纳入。 |
| [boundaries.md](boundaries.md) | 三种"不能"、固定图 vs 数据依赖结构、诚实天花板。 |

## 核心原则

- **能力边界是设计选择,不是天生定律**:绝大多数"不能"是"还没加构造",不是"做不到"。
- **三种不能要分清**:不能表示(设计选择)/ 不能验证(认知天花板)/ 不能可靠提取(LLM 能力)。
- **诚实优先**:覆盖不了就标注,绝不假装能做。`v1 是否纳入`列就是规范对外承诺的能力契约。
