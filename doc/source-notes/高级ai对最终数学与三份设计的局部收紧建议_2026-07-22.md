# 高级 AI 对最终数学与三份设计的局部收紧建议

> 日期：2026-07-22
> 性质：外部复审与本轮吸收记录，不是独立规范。最终结论见三份核心设计与
> [SCRC 数学总述](../IntentIR_SCRC_最终数学与执行流程_2026-07-22.md)。

## 复审结论

复审认可现有主架构，不建议增加 Agent、Gate、IR、前端 lowerer、RuleCard、mutation 主流程或
hash/commitment 设施：

```text
Lift_H(S) = (J,C,pi)
Replay = W_f(J,pi,MaskC(C);U_f)
SCRC_CERTIFIED iff TypeCheck(J,C,pi) and Gate1 and Gate2
```

建议只收紧数学定义、论文 claim 与相应派生 spec。

## 已吸收的修改

1. TypeCheck 只保证 closed-world artifact grammar 中没有新鲜的显式逻辑语义声明，并检查引用、
   route、observable J anchor 与 sensitive authorization；不宣称 π 没有统计语义线索，也不证明
   J 或 realization 的行为正确。
2. `SpecProj(J,C,pi)=J` 明确为显式语义所有权投影，不是实现行为集合等式。
3. J/B 只声明封闭 comparison class 与合同；外部政策 Q 决定可信 comparator、参数上限和异常
   处理。`Close_Q` 必须确定且对称，Lift 不能自定义及格线。
4. Gate2 直接检查 Source–Replay、Source–J 与 Replay–J 三条边，避免依赖浮点近似关系的传递性。
5. 当前主认证域明确为 deterministic / contract-deterministic Kernel。真正集合值语义只保留未来
   per-observation `Accept_{J,Q}` 方向；有限次 membership 不等于完整行为集合包含证明。
6. Replay allowlist 仍严格是 `J + pi + MaskC(C) + U_f`，并明确排除 source name/position、
   BindingMap、interface sidecar、fingerprint、旧 conversation 与 per-kernel RuleCard。
7. 主证书只覆盖实际绑定 `c0`。`forall c in Adm(J)` 是 C 的设计合同或额外 conformance 目标，
   不是单个 artifact 证书已经证明的结论。
8. Gate1 证书记录 frontend、observer profile/version、compiler/dump stage 与 canonicalization
   version；mutation test 只作为 observer sensitivity 的 CI/消融证据。
9. 实验报告区分首轮 TypeCheck、`closure@1/2/3`、Lift/Replay/总 LLM 调用、`NO_CLOSURE`
   分类与 Gate2 条件通过率。
10. masked-J 与主认证继续分离；`PROVED` 只是在记录的审计协议下观察到操作性必要性，
    J-authority challenge 保持可选离线消融。

## 额外数学收紧

- 概率上界针对 Gate1 后已经选定的完整候选 `a*=(J,C,pi,R)`。只有当该固定候选在分布 D 和 Q
  下的 Gate2 错误质量至少为 epsilon，iid 隐藏挑战全部漏检的概率才至多为
  `(1-epsilon)^m`。
- “错误 J”不自动意味着 epsilon 大于零；错误可能落在 D 的支持之外或被 Q 的观察关系合并。
- FIC/ESC 的“正交”只表示证明义务、失败模式与诊断职责不同且互不蕴含，不表示概率独立。

以上内容均是现有三对象架构的 claim 收紧，没有形成第四个设计对象或新的在线认证阶段。
